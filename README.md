# My CPU

A 32-bit CPU designed and implemented from scratch in Verilog.

## Tools

- Verilog
- Icarus Verilog
- GTKWave

## Architecture

- 32-bit
- RISC-style
- RISC-V inspired
- Single-cycle initially
- Simulation-first

## Project Status

Day 1 — Preliminary CPU architecture defined

### Current Architecture

- 32-bit CPU
- 32-bit instructions
- 8 general-purpose registers
- 32-bit program counter
- 10 initial instructions
- Single-cycle execution model
- RISC-style, RISC-V-inspired architecture
- Simulation-first development
